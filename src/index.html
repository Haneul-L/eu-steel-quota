GUIDE

How to read this dashboard

Key figures

  • Quota: the order's volume for this quarter (TARIC "Amount", incl. carry-overs), in tonnes.
  • Balance: what is left. Used = Quota − Balance.
  • Awaiting: requests waiting for allocation (TARIC "indicative" figure, not final).
  • Utilisation = (Used + Awaiting) ÷ Quota. It assumes all pending requests are granted, so it is a cautious figure.
  • TARIC usually publishes new allocations once per working day.

Status

  • OK: below 80% — quota available.
  • Watch: 80–90% — plan shipments carefully.
  • Critical: 90–100% — may run out within days.
  • Exhausted: 100% or no balance — imports pay the 25% safeguard duty unless another quota applies. New volume opens next quarter.

Türkiye and backup quotas

  • Wine-coloured rows (cream background) = the Türkiye-specific quota, or another quota Türkiye can use.
  • Where Türkiye has its own quota, the backup is FTA Quota – CSQ (residual pool after country quotas are used up).
  • Where Türkiye has no own quota, the backup is FTA Quota – Other countries.
  • Which residual quota actually applies depends on the regulation and origin rules — always confirm on the TARIC page before deciding.

By Country view

  • For each category, the selected country's own quota is shown.
  • If the country has no own quota in a category, the residual quota is shown instead (gold label): FTA Quota – Other countries for Türkiye and Korea, Other countries for all others.
  • Which residual quota applies depends on the country and origin rules — check the TARIC page.

Data source & freshness

  • Values come from the public EU TARIC quota pages. Click any order number to open the official page.
  • The header shows "Data as of". A shared file is a snapshot — it does not update by itself. Ask the Istanbul office for a newer file if it is old.
  • Order list and base volumes: Regulation (EU) 2026/1457, Annex I (valid 1 Jul – 31 Dec 2026). From 2027 the regime changes and this list must be updated.
